# Assets

- `frog/`: Crammy's sprite frames. See `frog/README.md` to swap in your own frog.
- `mascot.png` (optional): a square PNG with a transparent background, at least 256×256.
  If present it becomes the sidebar logo, browser tab icon and answer avatar instead of Crammy.
- `theme.css`: the pond theme (colours are variables at the top).
- `companion.js` / `companion.css`: Crammy's behaviour and look.
- `fonts/PixelifySans.woff2`: pixel display font, SIL Open Font License (`fonts/OFL.txt`).
  Bundled so the app works offline.
